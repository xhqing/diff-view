# diff-view-vsce

The VS Code side of the **[diff-view](https://github.com/xhqing/diff-view)** project: it silently closes the diff tabs that pi opened (via a request/ack file protocol), without stealing focus.

**This is one half of a two-part feature — install the pi-side companion (`diff-view-pie`) too.** Both halves are required; see the [project README](https://github.com/xhqing/diff-view#readme) for install instructions and how the two sides work together.
